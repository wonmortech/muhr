Этот файл существовал в этот день. Без изменений.

Muhr привязывает к Bitcoin и открытому журналу только хеш файла. Проверить доказательство может кто угодно, без нашего сервера.

Попробовать в браузере Следить на GitHub

Без токенаНе храним средстваФайл не покидает устройство

Иллюстрация: из документа выделяется хеш SHA-256 из 64 символов, он становится ободком сургучной печати, а печать через ветвь дерева Меркла связывается с блоком Bitcoin.

Иллюстрация
01 · Что доказывает

Доказывает «когда». Не «кто».

Говорим о границе сразу: печать показывает дату и целостность. Кто подписал, показывает сама подпись EIMZO.

Доказывает

  • Файл существовал к этой датеПо времени блока Bitcoin, с точностью до нескольких часов.
  • Не изменился ни один байтЕсли хеш другой, то и файл другой.
  • Проверяется без насДостаточно квитанции, открытого клиента ots и заголовков блоков Bitcoin.

Одна буква — совсем другой хеш. Поэтому хеш и называют отпечатком файла.

Не доказывает

  • Кто написал или подписалЭто даёт подпись EIMZO (PKCS#7). Muhr её только показывает.
  • Что содержание верноMuhr не читает и не оценивает файл.
  • Нотариальное заверениеЭто дополнительное, независимо проверяемое доказательство. Оно не заменяет официальную метку времени RFC 3161.
02 · Как работает

Пять шагов. Файл остаётся на вашем устройстве.

Отправляется только хеш из 64 символов. Всё остальное — открытые стандарты.

  1. Хеш

    SHA-256 считается в браузере или в CLI.

    Работает ниже

  2. Журнал

    Хеш записывается в открытый журнал Меркла, куда можно только добавлять (в стиле RFC 9162).

    Скоро

  3. Bitcoin

    Корень журнала попадает в блок Bitcoin через открытые календари OpenTimestamps. Это занимает несколько часов.

    Скоро

  4. Квитанция

    .muhr.json: доказательство включения и файл .ots. Её храните вы.

    Скоро

  5. Проверка

    Браузер, CLI или Telegram-бот. Работает, даже если нашего сервера уже нет.

    Скоро

Даже если Wonmor исчезнет, доказательство работает: проверка опирается на заголовки блоков Bitcoin и открытый клиент ots.

    CLI и журнал

07 · Честный статус
Сейчас это план. Кода пока нет.
Что есть и чего нет. Список обновляется раз в месяц.
Muhr никогда не просит деньги, ключи, seed-фразу или криптовалюту и никогда не пишет первым. Официальные адреса только muhr.wonmor.io и github.com/wonmortech.
